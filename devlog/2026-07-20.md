### v0.6.3 — Markdown Rendering (Tables + Formatting)

AI 输出的 markdown 表格和格式化内容在前端以纯文本显示，用户体验差。

**方案**：客户端 Markdown → HTML 转换。流式阶段保持 `textContent` 逐字追加；`done` 事件时通过 `marked` 库将完整文本转为 HTML。

**改动文件**：

| 文件 | 改动 |
|------|------|
| `templates/index.html` | +1 行 — 引入 `marked` CDN（`cdn.jsdelivr.net/npm/marked`） |
| `static/app.js` | `data.done` 处理：`marked.parse()` 转换后 `innerHTML` 替换；新增 `renderMarkdownMessages()` 处理页面重载时的历史消息；`data-rendered` 属性防重复转换 |
| `static/style.css` | +~100 行 — table/th/td/thead/tbody/tr 表格样式（Bloomberg 终端风）；通用 markdown 元素样式（h1-h6/p/strong/em/ul/ol/li/code/pre/blockquote/hr/a） |

**关键设计决策**：
- 不用服务端转换：流式 token 无法做块级 markdown 解析（表格需要完整行）
- `_messages` 保持存储原始 markdown（轻量、可移植）
- `data-rendered` 属性防重复转换（流式 `done` 转换过的消息不再被页面初始化函数处理）

**验证**：
- TestClient: marked CDN 注入正确、LANG_TEXT 未破坏、placeholder 正常
- Python 编译检查全部通过

  - `static/app.js`：无需改动（citations 先到即正常处理 → done 后 close）
- 效果：引用面板中的 WEB 来源显示为可点击链接（amber dotted underline + ↗ 标记），新标签页打开

**Bug 2: Agent Loop 达到最大迭代次数（Medium）**

- 根因：4 个共存设计缺陷：

  2. 工具错误消息引导循环 — `lookup_terms`/`get_company_data` 失败时明文建议"请使用 web_search"
  3. 计算器强制约束 — "严禁心算"让 LLM 对任何数字都调用工具
  4. 无重复检测 — LLM 可用不同措辞反复调用同一工具

- 修复（2 文件）：
  - `config.py`：中英文系统提示新增 "## 重要规则 / Important Rules" 段 — 信息足够后立即停止调用工具
  - `src/agent_loop.py`：
    - 3 处工具错误消息移除 `web_search` 建议（让 LLM 自行决策而非被引导）
    - Phase 1 循环增加 `called_tools` 集合追踪 `(tool_name, args_json)`，检测到重复即 `force_break` 退出循环

**Bug 3: urllib3 NotOpenSSLWarning（Low）**

### v0.6.6 — Inline Citation Markers

**需求**：在保留引用溯源面板的基础上，回答正文中使用 [1]、[2] 等行内标记对应引用来源，点击可跳转到面板中的具体条目。

**实现（5 文件）**：

| 文件 | 改动 |
|------|------|
| `config.py` | 中英文系统提示新增 "## 行内引用格式 / Inline Citation Format" 段，指导 LLM 使用 [1]、[2] 数字上标 |
| `src/agent_loop.py` | Phase 2 前注入编号引用索引：遍历 tracker 构建 `[1] WEB: Title\n[2] DOCUMENT: file · p5` 列表，作为 user 消息追加到 messages |
| `src/citation.py` | `format_panel()` 中每个 `.citation-item` 增加 `id="cite-N"` 锚点 |
| `static/app.js` | `data.done` 和 `renderMarkdownMessages()` 两处：markdown 渲染后将 `[N]` 正则替换为 `<sup><a href="#cite-N" class="inline-cite">[N]</a></sup>`；新增全局 click 委托：点击 `.inline-cite` → 自动展开 `<details>` 面板 + 2 秒高亮动画 |
| `static/style.css` | `.inline-cite` 样式（amber 上标、hover 高亮）；`.citation-highlight` 闪烁动画（amber glow → transparent, 2s） |

**数据流**：

```
Phase 1 结束 → tracker.to_list() → 构建编号索引
  → messages.append({role: "user", content: "可用来源索引:\n[1] WEB: ...\n[2] DOCUMENT: ..."})
  → Phase 2 chat_stream（LLM 看到索引，生成 [1] [2] 标记的回答）
  → Phase 3 citations SSE（面板 HTML 带 cite-N id）
  → app.js: marked.parse() → regex 替换 [N] → 可点击上标链接
  → 用户点击 [1] → 滚动到 #cite-1 → details.open = true → 2s 高亮
```

**示例效果**：
```
台积电2025年Q4营收为$33.73B¹，毛利率达到62.3%²。

¹ ² = 可点击上标，amber 色，点击跳转到引用面板
```

**验证**：
- Python 编译全部通过
- cite-N 锚点存在于 panel HTML
- Web 引用链接 + inline cite 链接共存不冲突
- 正则替换正确（`[1]` → `<a href="#cite-1">`）
- 系统提示包含中英文行内引用格式说明
