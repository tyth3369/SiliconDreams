# SiliconDreams v0.8.0

v0.8 将证据基础升级为可持续使用的个人研究工作台，并用真实官方年报基准验证检索质量。

## 数据与证据

- 收录台积电与中芯国际 2024 Q1–2026 Q2 官方季度实际值，保留两家公司披露口径差异。
- 引入来源可信等级、发布日期、时效状态和结构化事实冲突检测。
- 以 TSMC/SMIC 2025 官方年报建立 12 题中英双语人工 golden set；PDF URL、SHA-256、页码和关键文本均固定并核验。
- 修复真实复杂年报暴露的重复向量 ID、Chroma 元数据兼容、跨语言公司定位及财务段落漏召回问题。
- 正式基准结果：Recall@5 **100%**，MRR **84.03%**；发布门槛为 90% / 70%。

## 研究工作台

- PDF 上传改为 SQLite 持久后台任务，支持阶段进度、失败重试和服务重启恢复。
- 支持新建、自动/手动命名、切换、归档和恢复研究会话。
- 当前会话可导出为完整 Markdown 或 A4 PDF；保留表格、行内引用、原文片段及可点击来源链接。
- PDF 内嵌 OFL 许可的 Noto Sans SC 字体，中文显示不依赖阅读设备字体。

## 检索改进

- 检索调用严格兑现 `top_k`，不再被内部重排上限静默截断。
- 显式公司查询优先约束到对应报告，避免 TSMC/SMIC 互相挤占结果。
- 原始查询与双语财务术语扩展分别召回，再融合 BM25、BGE-M3 与 Cross-Encoder 结果。
- 指标证据覆盖度进入确定性终排，让包含所问数值口径的段落优先于泛化公司介绍。

## 部署边界

- 生产拓扑仍为 Caddy + 单 Uvicorn worker；默认 Basic Auth。
- 当前适合个人或小范围研究，不是公网多租户产品，也不构成投资建议。

## 验证

- Ruff format/check、uv lock 和安装依赖一致性检查通过。
- 128 项 pytest 回归测试通过，分支覆盖率 69.00%（门槛 60%）。
- 真实浏览器完成会话保留、双语、明暗主题、引用和导出控件回归。
