# SiliconDreams — UI/UX 设计规范 v0.7

## 视觉原则

保持专业金融终端感，不使用 emoji，不做卡片堆叠式消费应用设计。

| 模式 | 背景 | 强调色 | 主文字 |
|---|---|---|---|
| Dark | `#000000` | Amber `#ffb000` | `#e8e8e8` |
| Light | `#ffffff` | Deep Blue `#003d80` | `#1a1a1a` |

字体为 IBM Plex Mono / IBM Plex Sans。主题 CSS 变量以 `static/style.css` 为唯一事实来源。

## 布局

- 桌面端固定 280px 左侧栏；侧栏独立滚动。
- 主区由顶部栏、快捷操作、唯一可滚动聊天区和底部单线输入框组成。
- `html/body/main-area` 不滚动，避免聊天滚动带动侧栏。
- 暂以桌面宽屏为主，窄屏优化列入后续计划。

## 交互

- 主题：Auto / Dark / Light；浅色选中项必须白字蓝底，暗色选中项黑字琥珀底。
- 语言：中文 / English；局部 HTMX 更新，不刷新页面、不丢会话。
- 工具状态：开始、完成和耗时顺序保留；首个回答 token 出现时整体隐藏。
- Markdown：流式期间显示纯文本，完成后经 marked + DOMPurify 转换；表格使用固定终端样式。
- 引用：正文 `[N]` 为可点击上标，打开该消息的 source panel 并高亮目标；外部来源在新标签页打开。
- 输入提示仅表达“请输入您的问题”/“Please enter your question”。

## 动效

- 消息与引用面板淡入 200ms。
- 活跃工具状态以 1.5s 呼吸动画提示。
- 引用定位高亮 2s。
- 动效不得造成布局跳跃，不得遮挡或延迟核心操作。

## 不变约束

- 不重新引入 Streamlit。
- 不使用 emoji 作为状态或导航图标。
- 不增加可编辑式主题颜色配置。
- 功能重构不得改变已经确认的整体视觉风格。
