# SiliconDreams — UI/UX 设计规范

## 设计理念

**风格定位**：赛博朋克极客风 × 金融专业感

**关键词**：暗色、霓虹、精密、可信赖

**参考**：Bloomberg Terminal × Tesla CyberTruck UI × Matrix 代码雨

---

## 配色方案

### 主色调

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--bg-primary` | `#0a0a1a` | 主背景（接近纯黑） |
| `--bg-secondary` | `#111133` | 卡片/侧边栏背景 |
| `--bg-tertiary` | `#1a1a3e` | 输入框/代码块背景 |
| `--accent-primary` | `#00ff41` | 主霓虹绿（按钮、链接、高亮） |
| `--accent-secondary` | `#00d4ff` | 霓虹蓝（次要强调、引用标签） |
| `--accent-warning` | `#ffd700` | 金色（数据高亮、关键指标） |
| `--accent-danger` | `#ff4757` | 红色（下跌/风险/错误） |

### 文字色

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--text-primary` | `#e0e0e0` | 正文 |
| `--text-secondary` | `#a0a0b0` | 辅助文字 |
| `--text-dim` | `#606080` | 注释/占位符 |
| `--text-accent` | `#00ff41` | 强调文字（与主霓虹绿一致） |

## 字体系统

```css
/* 主字体：等宽优先，体现"终端/代码"感 */
--font-mono: 'JetBrains Mono', 'Fira Code', 'SF Mono', 'Cascadia Code', monospace;
--font-sans: 'Inter', 'SF Pro Display', -apple-system, sans-serif;
--font-display: 'Orbitron', 'Rajdhani', sans-serif; /* 标题专用，科技感 */

/* 字号层级 */
--text-xs: 0.75rem;    /* 12px - 脚注、标签 */
--text-sm: 0.875rem;   /* 14px - 辅助信息 */
--text-base: 1rem;     /* 16px - 正文 */
--text-lg: 1.25rem;    /* 20px - 小标题 */
--text-xl: 1.5rem;     /* 24px - 标题 */
--text-2xl: 2rem;      /* 32px - 大标题 */
--text-3xl: 2.5rem;    /* 40px - Logo */
```

### 间距规范

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-xs` | 4px | 紧密元素 |
| `--space-sm` | 8px | 相关元素分组 |
| `--space-md` | 16px | 标准间距 |
| `--space-lg` | 24px | 区块间距 |
| `--space-xl` | 32px | 大区块分隔 |

### 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | 4px | 小按钮、标签 |
| `--radius-md` | 8px | 卡片、输入框 |
| `--radius-lg` | 12px | 对话框气泡 |
| `--radius-full` | 9999px | 药丸按钮、状态指示灯 |

## 组件规范

### 聊天消息气泡

```
┌─ User Message ──────────────────────────┐
│ 背景: var(--bg-tertiary)                 │
│ 边框: 1px solid var(--accent-primary)   │ ← 霓虹绿描边
│ 对齐: 右对齐                             │
│ 圆角: --radius-lg (左上圆角缩小)         │
└─────────────────────────────────────────┘

┌─ AI Message ────────────────────────────┐
│ 背景: var(--bg-secondary)               │
│ 边框: 1px solid var(--accent-secondary) │ ← 霓虹蓝描边
│ 对齐: 左对齐                             │
│ 圆角: --radius-lg (右上圆角缩小)         │
│ 含: Markdown 渲染 + 引用标签            │
└─────────────────────────────────────────┘
```

### 快捷按钮

```
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│  🏭 行业对比      │  │  🔬 技术趋势      │  │  📊 财务分析      │
└──────────────────┘  └──────────────────┘  └──────────────────┘

状态:
- Default: bg-tertiary, border accent-primary
- Hover: bg-accent-primary, text bg-primary (霓虹绿填充)
- Active: 点击后闪烁动画 300ms
```

## 动画与微交互

| 元素 | 动画 | 时长 |
|------|------|------|
| 消息出现 | 淡入 + 上滑 10px | 300ms |
| 按钮 Hover | 霓虹辉光效果 (box-shadow) | 200ms |
| 流式文本 | 逐字出现（由 API 驱动） | 实时 |
| 引用展开 | 平滑下拉 | 300ms |
| 页面加载 | 终端风格启动画面 | 1.5s |
| 状态指示灯 | 脉冲动画 (在线/处理中) | 2s 循环 |

---

## 响应式

本阶段仅支持桌面端（≥1024px 宽度），移动端暂不适配。

- 侧边栏宽度：280px（固定）
- 主区域最小宽度：700px
- 聊天消息最大宽度：720px
