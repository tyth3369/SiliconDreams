# SiliconDreams v0.9.0

v0.9 将 v0.8 的证据与检索基础升级为可直接使用的半导体分析工作台。

## 新功能

- 可复用的中英双语公司对比模板，以及机器可读的指标定义、单位、可比性和派生规则。
- 台积电/中芯国际季度营收与毛利率趋势、FY2025 制程收入结构和 Capex 强度图；季度点直达官方来源。
- 持久化公司 Watchlist，以及完全由官方季度披露生成的事件时间线。
- Web 搜索缓存：普通查询 24 小时、时效性查询 15 分钟；结果摘要以内容哈希保存审计快照。
- 明确的公司财报/公告查询优先约束到公司或监管官方域名。
- 规范化术语图谱：稳定实体、双语别名、公司归一化、类型关系、双向闭合与自动审计。

## 质量与工程

- SQLite schema 升至 v4，自动迁移 Watchlist、Web 缓存与快照表。
- 新增真实 Chromium 端到端回归，覆盖主题、语言、数据图表、Watchlist 和对话保留。
- 新增无外部 API 的本机工作台性能基准。
- 术语图谱当前审计：309 个节点、1516 条边、0 个悬空端点、0 个缺失反向边、0 个别名冲突。

## 升级

```bash
git pull
uv sync --dev
uv run playwright install chromium  # 仅开发/测试需要
uv run uvicorn server:app --host 127.0.0.1 --port 8000 --reload
```

已有 SQLite 数据库会在启动时自动迁移。生产环境升级前仍建议备份 `data/`。
