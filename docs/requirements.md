# SiliconDreams — 需求规格 v1.0-rc.1

## 产品目标

为个人半导体研究者提供可核验、可计算、可持续更新的研究问答。系统不是通用聊天机器人，优先保证证据边界、计算正确性和来源可追溯性。

## 核心用户故事与验收

### 1. 上传财报并形成知识库

- 接受单个不超过 50MB、具有真实 PDF 签名的文件。
- 保存原始文件名与 SHA-256，重复上传保持幂等。
- 解析文本与表格，所有 chunk 具有真实 1-indexed 页码。
- SQLite 保存来源/文档/chunk 状态，Chroma 使用同一 chunk ID。
- 上传请求在文件安全落盘和任务入库后立即返回；后台任务显示解析、切块、证据保存和索引阶段，服务重启后可恢复中断任务。

### 2. 多路径证据检索

- Agent 可选择网页、上传报告、术语库和官方结构化财务数据。
- PDF 同时使用 BGE-M3 稠密召回和 BM25，RRF 融合后由 cross-encoder 重排。
- “最新”问题优先网页；财报问题优先本地 PDF/官方结构化事实。
- 检索质量通过人工 golden set 的 Recall@K/MRR 评估，不凭演示印象判断；v0.8 发布门槛为 Recall@5 ≥ 90%、MRR ≥ 70%。
- 引用质量使用真实 Agent 回答的人工 claim→source 标注集评估；发布门槛为 citation precision ≥ 95%、claim coverage ≥ 90%、编号有效率 100%。
- 每个 AI 请求必须可观测总耗时、首 token 延迟、模型/工具错误、API token、来源类型覆盖和可配置成本估算；遥测不得复制问题、回答或证据正文。

### 3. 精确财务分析

- 增长率、利润率、ROE/ROA、负债率、流动比率、估值、研发强度、差额和比例只由 Decimal 计算器生成。
- 计算器参数经过 Pydantic 校验；零分母等非法输入返回明确错误。
- LLM 只解释结果，不生成未计算数值。
- 台积电与中芯国际季度比较使用共同直接披露的美元营收和毛利率；中芯国际营业利润率由其披露的营业利润金额经计算器派生，不把不同披露口径伪装为同类原始指标。
- 公司对比模板从机器可读指标字典取得单位、定义、可比性和派生规则；快捷对比不得退回无口径约束的泛化提示。

### 4. 证据优先回答

- 每个可核验事实使用 `[N]` 行内编号。
- 编号对应同一消息下的来源面板。
- 网页/官方报告可在新标签页打开；PDF 显示原始文件名、精确页码和片段。
- 证据不足、冲突或过期时必须明确说明，不用模型记忆补全。
- 最新/近况类网页检索必须记录发布日期状态，排除未来日期结果；日期未知或过旧来源不得单独支撑“最新”结论。
- 同公司、同指标、同期间、同单位及币种的结构化事实出现不同数值时，必须向回答模型暴露冲突，不能静默选取。

### 5. 稳定 UI 与会话

- 保持 Bloomberg Terminal 风格：暗色黑/琥珀，浅色白/深蓝。
- 中文/英文与自动/深色/浅色切换不刷新或清空对话。
- 对话写入 SQLite，并以 HttpOnly conversation cookie 隔离。
- 侧栏可新建、自动/手动命名、切换、归档和恢复研究会话；归档不会删除消息或引用。
- Markdown 表格安全渲染；工具状态在回答开始时清除。
- 当前活动会话可下载为 UTF-8 Markdown 或 A4 PDF；两种格式均保留回答、表格、行内编号及完整来源元数据。

## 非功能要求

| 类别 | 要求 |
|---|---|
| 正确性 | 计算器测试必须全绿；引用必须指向实际检索结果 |
| 收敛性 | 每次请求最多一次检索规划和一次计算规划；无开放循环 |
| 安全 | 生产环境强制单账号认证、CSRF、安全 Cookie、分层限流、追加审计与 nonce CSP；secrets/用户资料不入 Git |
| 并发 | 同步模型、检索和重排不得阻塞 ASGI 事件循环 |
| 兼容 | Python 3.12；macOS Apple Silicon MPS，CPU 回退 |
| 可维护 | Ruff、pytest、CI、锁文件和开发日志持续同步 |

## 明确不承诺

- 不保证所有网页来源都准确；应优先官方披露并允许人工核验。
- 不构成投资建议，不执行交易。
- 当前不是公网多租户产品；只有共享单账号保护，不提供角色权限或合规审计系统。
- 术语库的 `related_terms` 可包含尚未建模的标签，不等同于全部闭合的知识图谱边。
