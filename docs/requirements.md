# SiliconDreams — 需求规格说明书

## 项目概述

**项目名称**：SiliconDreams（硅梦）

**项目定位**：电子/半导体行业专属 AI 助理分析师

**核心理念**：技术专家 + 财务分析师 = 智能投研大脑

**目标用户**：AI 初学者（个人使用），关注半导体行业的投资者/研究者

---

## 用户故事

### US-1：财报上传与知识库构建
> 作为分析师，我希望将半导体公司的财报 PDF 上传到系统中，系统自动解析并存储为可查询的知识库。

**验收标准**：
- 支持单个 PDF 文件上传（<50MB）
- 上传后自动完成：文本提取 → 表格识别 → 智能分块 → 向量化存储
- 侧边栏显示知识库状态：已索引文档数、最后更新时间

### US-2：自然语言财报查询
> 作为分析师，我希望用自然语言提问财报中的数据，系统返回精确数值而非模糊描述。

**验收标准**：
- 提问"Q3毛利率是多少？"→ 返回具体数字（如"57.8%"），并标注来源页码
- 表格数据不出现乱码、错位
- 支持多轮追问（如"那Q2呢？""同比变化多少？"）

### US-3：一键行业对比报告
> 作为分析师，我希望能一键生成多家公司的关键财务指标对比。

**验收标准**：
- 点击 [行业对比] 按钮 → 自动拉取已上传财报 → 生成对比表格
- 对比指标含：毛利率、净利率、ROE、研发投入比、同比/环比增长率
- 所有计算由 Python 精确完成（非 LLM 心算）

### US-4：技术趋势分析
> 作为分析师，我希望能查询某个半导体技术的商业影响和产业链关联。

**验收标准**：
- 查询"3nm制程"→ 返回定义、技术要点、相关公司、对毛利率/资本开支的影响
- 自动关联上下游技术（如 EUV 光刻、FinFET、GAA）
- 结合已上传财报中的数据做量化支撑

### US-5：引用溯源
> 作为分析师，我希望 AI 回答中的每个数据点都能追溯到原始报告的具体位置。

**验收标准**：
- 回答中每个数据引用标注 `[📎文件名 p页码]`
- 点击引用标签 → 展开显示原始段落文本
- 可人工核对 AI 输出是否忠实于原文

### US-6：财务深度分析
> 作为分析师，我希望系统能自动计算关键财务比率并生成分析报告。

**验收标准**：
- 支持 10 种财务比率自动计算
- 报告结构：摘要 → 行业背景 → 技术分析 → 财务分析 → 投资观点
- 所有比率计算由 Python 工具完成，100% 准确

- [x] FastAPI + HTMX Bloomberg 终端 UI
- [ ] 左侧边栏：PDF 上传 + 知识库状态
- [ ] 右侧主区：聊天界面 + 3 个快捷按钮

- [ ] 结构化报告生成

### Phase 4 — 打磨发布（Sprint 4-5）
- [ ] 引用溯源可视化
- [ ] 错误处理与性能优化
- [ ] README 文档

## 非功能需求

| 类别 | 要求 |
|------|------|
| **性能** | 单次 RAG 查询 <5 秒（不含 LLM 生成时间） |
| **可靠性** | 财务计算 100% 准确（Python 工具保证） |
| **可用性** | 全部本地运行，无需网络（除 LLM API 调用） |
| **安全** | API Key 不入库、Token 文件不入库 |
| **兼容性** | macOS + Apple Silicon (MPS 加速) |

---

## 约束条件

1. **中国大陆用户**：LLM API 仅接入 DeepSeek（国内可访问）
2. **本地优先**：Embedding、向量库、PDF 解析全部本地运行
3. **个人项目**：单用户设计，无需多租户/权限管理
4. **macOS 专属**：MPS GPU 加速为必需，非 Mac 平台仅做兼容回退
